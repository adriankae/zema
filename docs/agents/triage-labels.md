# Triage Labels

The engineering skills use five canonical triage roles. This file maps each role to the GitHub label used by this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an implementation agent |
| `ready-for-human` | `ready-for-human` | Human implementation is required |
| `wontfix` | `wontfix` | The issue will not be implemented |

When a skill names a canonical role, use the corresponding GitHub label from this table.
